# CIS225 – Data Structures (Spring 2026)

This repository contains my coursework for **CIS225 – Data Structures** at Triton College.

Throughout the semester, I strengthened my C++ programming skills by implementing fundamental data structures and algorithms from scratch. Topics included object-oriented programming, dynamic memory allocation, linked lists, binary trees, binary search trees, recursion, sorting algorithms, and file processing.
